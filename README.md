# 草野球AI査定 Ver.64 — 総合値バランス調整

総合値100が出やすかったため、単純な加算方式を調整。

新しい考え方:
- 基礎: 従来の打撃・走塁・守備能力
- 守備適性: 最大 +4
  - 最高適性だけでなく、守れるポジション数も少し評価
  - 守備力そのものとの二重加点を抑制
- 投手能力: 最大 +6
  - 球速25% / 制球35% / スタミナ25% / 投手適性15%
  - 野手能力にプラスαする方式は維持
- 89以上の高能力帯は加点を55%に圧縮
- 総合値上限は99

これにより「投手・守備適性があるだけで一気に100」になりにくくし、
90台を本当に能力の高い選手向けのレンジに調整。
